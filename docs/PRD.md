> 基于 Octarine 官方文档（docs.octarine.app）深度分析
> 分析日期：2026-03-23

## 一、产品概述

### 1.1 产品定位

**Octarine** 是一款**快速、私密的本地优先 Markdown 编辑器**，基于 **Rust + Tauri** 技术栈构建，安装包仅 **~30MB**，是一款"固执己见"（Opinionated）、开箱即用的个人知识管理（PKM）工具。

核心理念是：
- 用户完全掌控自己的数据（local-first）
- 无需订阅即可使用核心功能
- AI 辅助写作与知识管理深度融合

### 1.2 核心设计理念

- **性能优先**：Rust 底层引擎处理文件系统操作、全文搜索、文件监听和向量嵌入，启动速度和操作响应远超同类 Electron 应用
- **本地优先**：所有数据以纯 Markdown 文件存储在用户本地设备，无云锁定
- **开箱即用**：核心功能无需安装插件，拒绝构建第三方插件生态，提供完整闭环体验
- **隐私保障**：默认不联网，仅在用户主动触发更新、AI 功能时才会产生网络请求
- **无干扰设计**：WYSIWYG 编辑器界面简洁，专注于内容创作

### 1.3 目标用户画像

| 用户类型 | 核心需求 |
|---------|---------|
| 知识工作者 | 快速记录、整理想法、建立知识库 |
| 写作者 | 专注写作、AI 辅助润色、无干扰环境 |
| 开发者 | 代码块、Mermaid 图表、LaTeX 数学公式 |
| 隐私敏感用户 | 本地存储、无云锁定的数据架构 |
| AI 爱好者 | 支持 Ollama/LM Studio，完全离线使用 AI |

### 1.4 核心价值主张

```
┌──────────────────────────────────────────────────────┐
│  "Your ideas, your data, your AI — all offline"       │
│                                                        │
│  1. 本地优先 → 数据完全属于用户                          │
│  2. Markdown 格式 → 永久可移植，无工具绑定               │
│  3. AI 深度集成 → 写作助手 + 知识问答 + 每周回顾        │
│  4. 知识图谱 → 可视化洞察笔记间的关联                    │
└──────────────────────────────────────────────────────┘
```

## 二、功能需求详述

### 2.1 编辑与格式化（Core Editing）

#### 2.1.1 WYSIWYG Markdown 编辑器

- **底层技术**：基于 Tiptap + Prosemirror 构建
- **所见即所得编辑**：无需预览，实时渲染 Markdown 格式，彻底摒弃"左侧源码、右侧预览"的割裂模式
- **重要限制**：不是 Markdown 源码编辑器，无法切换到源码视图，渲染后始终为富文本
- **自动保存**：输入时自动保存，无需手动操作
- **撤销/重做**：`Cmd/Ctrl + Z`（撤销），`Cmd/Ctrl + Shift + Z`（重做）
- **查找替换**：`Cmd/Ctrl + F` 当前笔记内搜索替换，支持正则表达式、大小写敏感、全词匹配
- **快捷键体系**：标准格式化快捷键（Cmd/Ctrl + B/I/K 等）
- **浮动菜单（Bubble Menu）**：选中文字后弹出格式化工具栏（加粗、斜体、高亮、链接、转换区块等）
- **斜杠命令（Slash Command）**：新行输入 `/` 触发可搜索的上下文插入菜单，快速调取标题、样式、组件和模板
- **多光标编辑**：类似 VS Code，支持同时编辑多处
- **实时字数统计**：可选显示
- **换行控制**：
  - `Enter`：创建新段落
  - `Shift + Enter`：同一段落内换行
  - 不支持 Markdown 多个连续空行（刷新后会被还原）

#### 2.1.2 支持的格式化元素

| 类别 | 功能项 |
|------|--------|
| **文本** | 粗体、斜体、删除线、下划线、文本颜色（8种预设颜色）⭐ Pro |
| **结构** | 多级标题（Heading Font 自定义字体）、可折叠标题（Collapsible Headings） |
| **块级** | 代码块（70+ 种编程语言语法高亮）、表格（支持单元格间自动导航）、Callout 提示框 |
| **高级** | Mermaid 图表（流程图、时序图、甘特图等）、LaTeX 数学公式（支持块级 Block Math） |
| **媒体** | 附件嵌入（图片拖放/粘贴、文件），自动保存到 `.attachments` 文件夹 |
| **链接** | Doclinks（笔记间双向链接）、外部 URL |

#### 2.1.3 Callout 提示框类型

系统内置五种语义化标注类型，底层仍为标准 Markdown 引用块（Blockquote），保持兼容性：

| 类型 | 用途 |
|------|------|
| 信息（Info） | 一般说明信息 |
| 警告（Warning） | 注意事项 |
| 错误（Error） | 错误/危险提示 |
| 成功（Success） | 完成/正面反馈 |
| 提示（Tip） | 技巧/建议 |

- 支持深度嵌套：内部可混排列表、文档链接、代码块等

#### 2.1.4 Doclinks（文档双向链接）

- **语法**：使用 `[[目标文件名]]` 双中括号语法
- **三种创建方式**：
  1. 手动在编辑器中键入 `[[` 双括号语法
  2. 输入 `[[` 后系统弹出搜索下拉菜单，搜索并选择目标笔记
  3. 从侧边栏文件树拖拽笔记到编辑器光标处，自动生成链接
- **自动链接管理**：文件重命名或移动时，系统自动更新整个工作区内所有指向该文件的链接，彻底消除"死链"问题
- **悬浮预览**：鼠标悬停在链接上时，自动弹出目标文档内容预览窗口
- **反向链接面板（Backlinks Panel）**：每篇笔记底部自动展示所有引用了当前笔记的其他页面及上下文片段
- **新建链接**：若输入的文件名不存在，系统提示在当前文件夹或根目录创建新笔记

#### 2.1.5 写作辅助

- **专注模式（Focus Mode）**：高亮当前句子或段落并暗化背景文本，提供不受干扰的纯粹写作环境
- **大纲导航（Outline Navigation）**：侧边栏快速跳转标题
- **只读笔记**：锁定特定笔记防止误修改 ⭐ Pro
- **文本拖拽移动**：支持拖拽选中文本到其他位置
- **内联文档链接预览**：悬停显示链接文档预览（v0.38.1）
- **文档链接历史记录**：追踪文档链接访问历史（v0.38.1）

### 2.2 组织与管理（Organization）

#### 2.2.1 多工作区（Workspaces）

- **概念**：每个 Workspace = 本地文件系统上的一个文件夹
- **创建方式**：
  - Create New：新建空白文件夹
  - Open Existing：挂载已有文件夹为 Workspace
  - Import from Git：克隆 Git 仓库作为 Workspace
- **隔离性**：工作与生活笔记完全隔离，独立配置
- **设置克隆**：可在创建新 Workspace 时复用已有 Workspace 的配置（主题、编辑器偏好、AI Keys 等）

#### 2.2.2 文件树（File Tree）

- **层级结构**：完全镜像本地文件系统的实际组织方式，支持无限嵌套
- **实时同步**：自动更新，外部文件操作即时反映
- **文件夹图标自定义**：每个文件夹可设置专属图标，加速视觉识别
- **文件夹排序自定义**：可打破默认字母顺序，为不同层级设置独立排序规则 ⭐ Pro
- **视觉指示器**：显示文件夹内笔记总数（含嵌套），已创建每日笔记的日期显示圆点标记
- **创建操作**：
  - 新建笔记：`Cmd/Ctrl + N`（默认名 "Untitled.md"）
  - 新建文件夹：`Cmd/Ctrl + Shift + N`
  - `Cmd/Ctrl + 点击`：在当前笔记所在文件夹创建
  - 支持从 Finder/Explorer 拖放 Markdown 文件到文件树
- **移动内容**：拖放笔记/文件夹到目标文件夹，支持悬停自动展开（200ms 延迟）
- **复制笔记**：`Cmd/Ctrl + C` 创建带 "_copy_" 后缀的副本
- **删除**：右键菜单或 `Cmd/Ctrl + Backspace`，**永久删除（不进回收站）**
- **快速导航**：`Cmd/Ctrl + P` 快速文件搜索和跳转
- **聚焦文件树**：`Cmd/Ctrl + Shift + E`，使用箭头键导航
- **排序**：默认按文件名 A-Z 排序，目录在前笔记在后；支持按修改日期排序

#### 2.2.3 标签系统（Tagging）

- 在笔记中使用 `#标签名` 打标签
- **支持嵌套标签**：如 `#work/projects/2024`，实现层级化标签体系
- 标签可注入 YAML Frontmatter 或直接穿插在文本段落中
- 标签自动汇聚，支持标签筛选
- 标签在知识图谱中作为独立节点存在

#### 2.2.4 属性与元数据（Properties） ⭐ Pro

- **Frontmatter 支持**：每个笔记可定义 YAML 属性块
- **属性类型**：String（字符串）、Number（数字）、Date（日期）、Checkbox（布尔）、List（列表）、Tags（标签）
- **全局注册表**：工作区根目录下的 `properties.json` 定义所有可用属性的架构（字段名、数据类型、验证逻辑）
- **用途**：
  - 任务状态（待办/进行中/完成）
  - 创建时间、修改时间
  - 自定义字段（项目名、优先级等）
- **可搜索**：支持按属性过滤笔记
- **与视图联动**：属性须先在 `properties.json` 中定义并至少应用于一篇笔记，才能在视图中使用

#### 2.2.5 视图（Views） ⭐ Pro

- **本质**：持续监听与自我更新的"智能保存搜索"（Smart Saved Searches）
- **查询逻辑**：严格的 AND 逻辑，笔记必须同时匹配所有过滤条件才会显示
- **过滤维度**：

| 数据类型 | 可过滤字段 | 支持的操作符 |
|---------|-----------|------------|
| 字符串型 | 文件名、路径、文件夹 | 等于、包含、不包含 |
| 时间序列型 | 创建日期、修改日期 | 前于、后于、今天、过去7天、本季度等 |
| 列表/关系型 | 标签、链接笔记、关联附件 | 存在性验证，支持分裂渲染（一篇笔记可同时出现在多个标签组中） |
| 布尔型 | 任务状态、是否置顶、是否锁定 | 是/否 |

- **实时预览 + 延时提交**：过滤条件变动即时预览效果，需手动点击保存才固化；视觉设置（列宽、排序）即时自动保存
- **分组功能（Grouping）**：
  - 按分类属性分组，插入可折叠导航头
  - 连续型数据智能分桶（如字数 <100、100-500；日期"本周"、"上个月"）
  - 黏性滚动（Sticky Scrolling）：当前组别标题始终固定在视口顶部
- **看板视图（Kanban Views）**：在表格与看板布局间无损切换，卡片可在代表不同状态的纵列间拖拽
- **滑动预览抽屉（Preview Sheet）**：
  - 点击笔记名称，右侧滑出只读完整预览
  - 显示字数、预计阅读时间、可编辑的属性面板
  - 支持 VIM 快捷键（j/k）在文档间切换
  - 需要深度编辑时点击 "Edit in Tab" 进入全屏编辑
- **默认视图**：
  - **已整理的知识库**：按最后修改时间降序展示所有笔记
  - **待处理任务集**：汇总所有未完成的复选框任务
  - **近期创作轨迹**：展示过去7天内有变动的活跃笔记

#### 2.2.6 模板（Templates）

- **存储位置**：工作区根目录下 `.templates` 文件夹，模板本身为标准 Markdown 文件
- **区块式插入**：在编辑过程中输入 `/` 调用斜杠命令搜索模板名称，将模板内容注入到当前光标位置（不强制生成新笔记）
- **从模板创建笔记**：通过 `Cmd/Ctrl + K` → "Create note from template" 生成独立笔记，自动继承模板的 YAML Frontmatter 属性
- **模板变量引擎**：支持 `{{variable}}` 双大括号占位符，调用时自动替换
  - `{{title}}`：自动填充当前笔记的文件名（去除 .md 后缀）
  - `{{date}}`：当前日期
  - `{{time}}`：当前时间
  - `{{date:FORMAT}}`：自定义日期格式（如 `{{date:MMMM d, yyyy}}`），基于 date-fns 语法
  - `{{time:FORMAT}}`：自定义时间格式（如 `{{time:HH:mm}}`）
  - 变量可在 Markdown 正文和 YAML Frontmatter 属性值中使用

#### 2.2.7 置顶与锁定

- 置顶笔记 / 置顶文件夹
- 只读笔记（防止误编辑）

### 2.3 界面布局与窗口管理（UI & Layout）

#### 2.3.1 三栏式布局

- **左侧边栏（Sidebar）**：文件树（Notes）、每日工作台（Daily Desk）、模板库（Templates）、视图（Views）、附件管理（Attachments）；底部集成交互式日历组件
- **中央编辑区**：Markdown 渲染与编辑画布，支持多标签页与分屏
- **右侧元数据面板（Meta Sidebar）**：显示笔记元数据（创建时间、修改时间、字数、预计阅读时间）、反向链接面板、大纲导航；亦可用于 AI 助手交互
- **可折叠边栏**：支持隐藏左右边栏，进入专注写作模式
- **状态栏**：显示当前文件路径、字数、保存状态

#### 2.3.2 多标签页（Tabs）

- 支持同时打开多个笔记，类似浏览器标签页
- 标签页支持拖拽排序
- `Cmd/Ctrl + W` 关闭当前标签页
- 通过命令面板或文件树点击在新标签页中打开笔记

#### 2.3.3 分屏视图（Split View） ⭐ Pro

- **版本**：v0.39.0 新增
- **垂直分屏**：左右并排显示两个笔记
- **水平分屏**：上下并排显示两个笔记
- **比例调整**：支持拖动分隔线调整分屏比例
- **独立滚动**：每个面板独立滚动和编辑
- **使用场景**：参考一个笔记的同时编辑另一个、对比两个版本的内容、跨笔记拖拽内容

#### 2.3.4 命令面板（Command Palette）

- **入口**：`Cmd/Ctrl + K` 全局快捷键
- **定位**：快速执行命令、导航、创建内容的统一入口
- **支持命令**：
  - **快速导航**：Go to Date、打开笔记、跳转到文件夹
  - **创建内容**：新建笔记、新建文件夹、创建每日笔记、从模板创建
  - **编辑器操作**：插入代码块、插入表格、插入分割线
  - **应用设置**：切换主题、刷新数据库（Refresh Database）、配置 AI
  - **窗口管理**：切换工作区、关闭当前标签
- **智能提示**：
  - 支持模糊搜索
  - 最近使用命令优先显示
  - 命令按类别分组（导航、创建、编辑、设置）

### 2.4 每日工作台（Daily Desk）

#### 2.4.1 核心概念

- **功能定位**：专门处理每日/每周条目的日志系统，与常规知识笔记分离，降低快速记录（Quick Capture）的心理负担
- **文件存储**：
  - 每日笔记：`Daily/YYYY-MM-DD.md`（如 `2025-02-09.md`）
  - 每周笔记：`Daily/Weekly/YYYY-W<周数>.md`（如 `2025-W3.md`）
- **视觉提示**：侧边栏日历中已创建笔记的日期下方显示圆点标记，悬停可预览内容
- **默认展示**：每次打开 App 优先展示 Daily Desk

#### 2.4.2 日历导航

- **点击日期**：直接打开或创建当天笔记
- **快捷键导航**：支持方向键、Home/End、PgUp/PgDn 在日历中快速移动
- **智能日期跳转**：`Cmd/Ctrl + K` → "Go to Date"，支持自然语言输入

#### 2.4.3 智能日期（Smart Dates）

- **触发**：命令面板 `Cmd/Ctrl + K` → "Go to Date"，或 `Cmd/Ctrl + D`（跳转到今日）
- **支持的日期格式**：
  - **相对日期**：`today`、`yesterday`、`tomorrow`、`next week`
  - **具体日期**：`March 15th`、`December 1st, 2024`
  - **星期几**：`last Monday`、`next Friday`、`this weekend`
  - **上下文短语**：`in two days`、`three weeks ago`
- **自然语言解析引擎**：毫秒级将口语化时间短语翻译为系统时间戳格式

#### 2.4.4 任务自动迁移（Migrate Incomplete Tasks）

- 未完成任务自动从昨日迁移到今日
- 确保待办事项不遗漏

#### 2.4.5 特色功能

- **任务计数器**：自动统计所有每日笔记中的任务总数，显示完成进度
- **快速记录**：提供专注的每日记录空间，避免常规笔记干扰
- **时间线视图**：支持按周、月查看历史记录

#### 2.4.6 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Cmd/Ctrl + D` | 打开今日笔记 |
| `Cmd/Ctrl + Shift + D` | 打开本周笔记 |
| `Cmd/Ctrl + Alt + ←/→` | 在日期间快速跳转 |

### 2.5 知识发现（Knowledge Discovery）

#### 2.5.1 知识图谱（Graph） ⭐ Pro

- **节点类型**：
  - 普通笔记节点（每个 .md 文件）
  - 周期性笔记节点（每日/每周笔记）
  - 标签节点
- **边（连接）**：
  - 实线：`[[Doclinks]]` 双向链接
  - 标签聚类：共享标签的笔记围绕标签节点聚集
- **交互**：
  - 点击节点 → 打开笔记
  - 悬停 → 显示标题和连接数
  - 拖拽节点 → 物理模拟重排（会话级，不保存）
- **搜索定位**：`Cmd/Ctrl + F` 在图谱中高亮匹配节点
- **孤立笔记标识**：未链接的节点清晰可见，提示用户补充关联

#### 2.5.2 工作区搜索（Workspace Search）

- **触发**：`Cmd/Ctrl + Shift + F` 或侧边栏搜索框
- **搜索选项**：
  - 全文搜索（标题 + 内容）
  - 标签过滤（`#project`）
  - 正则表达式（Regex）
  - 单词匹配 / 大小写敏感
  - 指定范围（Daily Desk / Templates 等）
- **结果展示**：标题高亮 + 内容预览 + 点击跳转
- **键盘导航**：↑↓ 浏览，Enter 打开，Esc 退出

### 2.6 AI 能力（AI Features） ⭐ Pro

#### 2.6.1 AI 架构设计

#### 2.6.2 AI 配置管理

**设置路径**：Settings → AI Assistant → Providers

**配置步骤**：
1. 选择 AI 提供商类型（云端服务或本地服务）
2. 输入 API 密钥或本地服务 URL
3. Octarine 自动验证连接，显示勾选标记
4. 支持同时启用多个提供商，随时切换

**支持的 AI 服务**：

| 类型 | 提供商 | 说明 |
|------|--------|------|
| 云端 | OpenAI | GPT 系列模型 |
| 云端 | Anthropic | Claude 系列模型 |
| 云端 | OpenAI-compatible API | 兼容 OpenAI 接口的第三方服务 |
| 本地 | Ollama | 开源本地模型框架，默认 `http://localhost:11434` |
| 本地 | LM Studio | 本地模型 GUI，默认 `http://localhost:1234` |

**Ollama 集成**：
- 安装：从 ollama.com 下载安装
- 拉取模型：`ollama pull llama2`（或其他模型）
- 启动服务：`ollama serve`
- 安全性：API 默认只监听 localhost，不暴露到互联网

**LM Studio 集成**：
- 下载模型：在应用内模型库中选择并下载
- 启动服务器：API 选项卡中点击 "Start Server"
- 模型管理：在 LM Studio 界面直接管理模型

**安全设计**：API 密钥存储在本地 `.store.dat` 文件，不上传云端

#### 2.6.3 模型选择与管理

- **模型选择器**：配置提供商后，下拉菜单显示可用模型（按提供商分组）
- **模型信息**：显示上下文窗口大小和关键特性
- **会话记忆**：最后选择的模型在不同会话间保持
- **切换方式**：AI 面板或编辑器工具栏访问模型选择器
- **建议**：为节省时间和成本，建议选择非代码生成的轻量级模型

#### 2.6.4 Writing Assistant（写作助手）

- **触发**：`Cmd/Ctrl + J` 打开侧边栏
- **上下文感知**：默认以当前笔记为上下文；可选中文字后以选中内容为输入
- **@-提及（AI Context Chips）**：
  - 在提示框输入 `@` 引用其他笔记或文件夹作为额外上下文
  - 支持多笔记/文件夹同时引用
  - 上下文以"芯片"（Chips）形式显示在输入框中
- **内联 @提及**：编辑器中直接 @ 提及其他笔记，创建双向链接
- **研究模式（Research Mode）**：
  - AI 先主动提问收集信息，不急于生成长篇内容
  - 信息充足后提供草稿选项
  - 支持继续讨论或转向
- **Web 搜索（Beta）**：
  - 开启后 AI 可引用网络资源（支持 OpenAI & Claude 模型）
  - 输入框下方工具栏"地球图标"开关控制
- **响应操作**：
  - Copy / Insert（插入光标位置）/ Replace（替换选中内容） / Retry / Delete
- **自定义斜杠命令**：
  - Settings → AI Assistant → Slash Commands 创建
  - 配置保存：`.octarine/ai/slash-commands.json`
  - 支持 `/summarize`、`/translate`、`/review` 等常用命令
- **聊天记忆**：同一会话记住上下文，支持修改历史提问重新生成
- **编辑历史**：点击聊天记录中任一提示可重新编辑

#### 2.6.5 Ask Octarine（知识问答）

- **触发**：`Cmd/Ctrl + O` 或侧边栏按钮
- **核心能力**：用自然语言询问自己的笔记，AI 基于笔记内容回答
- **本地向量索引**：
  - 首次使用下载 90MB Embedding 模型（完全本地运行，ONNX 格式）
  - 笔记自动分块建索引（Tokenization + 向量化），存入本地 SQLite 向量数据库
  - 新增/修改/删除笔记触发增量更新，无需全量重建
- **@-提及增强（Context Chips）**：
  - **物理层级锚定**：@ 提及特定笔记文件名或框选整个文件夹
  - **时间滤镜**：基于创建日期（Created Date）或修改日期（Modified Date）过滤
  - **Daily Desk 范围**：框选特定日期范围的日志（如"上周一至本周五"）
  - 过滤策略具象化为输入框内高亮排列的交互式"上下文芯片"（Context Chips）
- **引用溯源**：
  - AI 回复下方展示"引用溯源列表"（References）
  - 通过图标与悬浮卡片展示 AI 参考的具体笔记来源
  - 从根本上抑制大语言模型幻觉（Hallucination）
- **隐私保障**：
  - Embedding 计算完全本地
  - 仅查询时将提示词 + 相关文本块发送给 AI 提供商
  - 配合 Ollama 使用可实现全链路本地（零网络请求）
- **建议提示词**：空对话时随机展示基于笔记内容的建议问题
- **历史记录**：按相对日期组织（今天、昨天、2天前、1周前），存储在 IndexedDB 中
- **导出对话**：可复制为 Markdown 或纯文本；可保存整个对话为新笔记

#### 2.6.6 Weekly AI Recap（每周 AI 回顾）

- **入口**：在每周笔记页面点击 "Generate Recap"
- **两种模式**：
  - **主题回顾（Thematic Review）**：分析一周笔记中的主题、模式和成就
  - **每日回顾（Daily Recap）**：按时间线逐日总结
- **追加到笔记底部**：保留原有内容，只在末尾追加 AI 总结
- **接受/拒绝机制**：
  - 拒绝后可重试
  - 接受后 frontmatter 添加标记，该按钮不再显示
- **语言一致性**：用笔记撰写语言生成总结

#### 2.6.7 AI 提供商管理

- **BYOK 模式（Bring Your Own Key）**：用户自带 API 密钥
- **支持的云端**：OpenAI（GPT 系列）、Anthropic（Claude 系列）、OpenAI-compatible API
- **支持的本地**：Ollama、LM Studio
- **多提供商同时启用**：一个下拉框切换所有可用模型（按提供商分组）
- **Key 安全**：API Keys 本地加密存储（`.store.dat`），永不上传

### 2.7 数据架构（Data Architecture）

#### 2.7.1 本地优先存储

| 数据类型 | 存储位置 | 格式 |
|---------|---------|------|
| 笔记内容 | Workspace 文件夹 | `.md` 纯文本 |
| 配置文件 | OS 配置目录 | `.store.dat` (JSON) |
| 索引数据 | IndexedDB | 浏览器引擎数据库 |
| AI 对话记录 | IndexedDB | 浏览器引擎数据库 |
| 斜杠命令配置 | Workspace 内 `.octarine/ai/slash-commands.json` | JSON |

**配置文件路径**：
- macOS：`~/Library/Application Support/Octarine`
- Windows：`%AppData%\Roaming\Octarine.app`
- Linux：`~/.config/Octarine.app`

#### 2.7.2 核心设计原则

```
数据主权：配置文件永不联网，完全设备本地
文件可移植：.md 文件任意迁移，无供应商锁定
实时同步：Workspace 文件夹被持续监听，外部修改即时反映到 App
云盘兼容：Workspace 可建在 iCloud/Dropbox/OneDrive 等本地同步盘
外部编辑：纯文本文件可用任意编辑器修改
```

#### 2.7.3 数据库刷新机制

- `Cmd/Ctrl + K → Refresh Database` 强制重建索引
- 解决外部大量修改后的索引不一致问题

### 2.9 定制化（Customization）

#### 2.9.3 URI Scheme 与外部自动化

- **协议**：`octarine://` 自定义 URI 深度唤醒方案
- **用途**：允许外部工具（Apple Shortcuts、Raycast、Alfred、自定义脚本）与 Octarine 通信
- **参数传递**：遵循查询字符串（Query String）标准，如 `octarine://host?action=<动作>&param1=值1`
- **x-callback-url 支持**：完整支持双向回调协议
  - `x-success`：操作成功后的回调 URL
  - `x-error`：操作失败时的回调 URL
  - `x-cancel`：用户取消时的回调 URL
- **支持的动作**：创建笔记、打开笔记、导航到指定路径等
- **无头模式（Headless Execution）**：外部工具可在不弹出前台窗口的情况下执行操作

- Embedding 模型完全设备本地运行（90MB 模型），笔记内容不上传服务器
- 无云端数据同步（除非用户主动配置）
- Git/Sync 等外部服务由用户自行管理

### 5.4 更新机制

- 支持 macOS `.dmg`、Windows `.msi`、Linux `.AppImage` 的自动更新
- 每 24 小时自动检查更新
- 支持手动检查更新（`Cmd/Ctrl + K` → Check for updates）
- 用户可手动控制是否启用自动更新

### 5.5 可访问性

- 键盘快捷键全覆盖（键盘优先设计）
- 响应式布局适配不同窗口大小
- 拖放支持：文件拖放、图片拖放、文本拖放
- 上下文菜单：右键菜单提供常用操作

## 十、风险分析

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| AI 竞品快速跟进 | 差异化优势削弱 | 深耕本地 AI + RAG，保持功能领先 |
| Obsidian 生态护城河 | 用户迁移意愿低 | 完全兼容 Obsidian Vault，降低迁移门槛 |
| 本地 AI 模型性能受限 | 用户体验不如云端 | 优化 Embedding 模型，持续跟进本地模型进展 |
| 跨平台一致性 | 各平台体验不统一 | Tauri + Rust 保证核心逻辑统一 |
| 单人/小团队开发 | 功能迭代速度有限 | 聚焦核心差异化功能，避免功能过度膨胀 |
| 一次性定价模式 | 长期营收可持续性 | "提前访问"渐进提价模型，新用户持续带来收入 |

## 十二、总结

Octarine 是一款定位清晰的**本地优先 AI 增强型 Markdown 编辑器**，其核心竞争力在于：

1. **本地数据主权**：.md 文件本地存储，无云锁定
2. **全链路本地 AI**：支持 Ollama + 本地 Embedding，数据永不离开设备
3. **独特 AI 功能**：Ask Octarine（RAG 知识问答）+ Weekly AI Recap（每周回顾）
4. **知识图谱可视化**：笔记网络化，发现隐藏关联
5. **合理商业模式**：一次性买断 Pro，无订阅疲劳
6. **极致轻量**：Tauri + Rust 架构，安装包 < 30MB，内存占用低于同类 90%

**核心差异化**：唯一一个将"本地 AI + RAG 知识问答 + 每周回顾"深度集成在本地方案中的 Markdown 编辑器。
