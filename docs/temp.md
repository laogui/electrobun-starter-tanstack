脑暴观察

✅ 做得很好的部分

- Local-First 数据架构设计得很成熟——内容/布局解耦、noteId≠nodeId、unplaced notes
  的生命周期管理，这些都是长期可扩展的基础
- 交互状态机定义清晰，7 个状态 + 优先级规则，避免了很多"手势冲突"的坑
- Folder children 内嵌 → 后续迁移独立 .md 的渐进策略很务实

🤔 值得再想想的点

1.  选择模型重构（P0 #4）是当前最大的体验断层

- 目前单击直接聚焦，跳过了 selected 状态——这意味着用户没有"轻触预览"和"批量操作"的能力
- 建议优先做这个，因为后续的框选、批量拖入 Folder、复制粘贴都依赖 selected 状态

2.  Folder 的"只进不出"感知

- PRD 提到了 Extract to Canvas，但用户发现性可能很低（藏在右键菜单里）
- 可以考虑：drill-down 视图顶部加一个明确的 ↗ Extract 按钮，或支持长按拖出的手势暗示

3.  搜索的 unplaced notes 问题

- 目前设计是"仅通过搜索可达"——但如果用户不知道有 unplaced notes 的概念，这些内容就等于丢了
- 建议在侧边栏或某个角落加一个 📦 Unplaced (3) 的入口，哪怕 MVP 只是个计数 badge

4.  语义缩放是个被低估的差异化亮点

- PRD 提到了"极小比例下只显示色块和标题"，但没有详细定义缩放阈值和过渡层级
- 这个做好了会非常惊艳（参考 Muse/tldraw），建议专门出一个缩放层级的设计 spec

5.  缺少"模板"概念

- 用户每次从空白卡片开始效率较低
- 可以考虑：预置几种卡片模板（会议纪要、读书笔记、SWOT 分析），从 CreateMenu 直接选

6.  导出/分享能力偏弱

- PNG/JSON 导出是有的，但没有"分享一个只读链接"或"导出为 PDF"
- 作为个人知识库，"把一块画布截图发给别人"是高频场景

7.  远期路线缺少"链接/反向链接"

- 作为知识库产品，笔记之间的双向链接（[[note]] 语法）几乎是刚需
- 可以和 Edge 系统互补：Edge 是显式的视觉关系，backlink 是隐式的内容关系
