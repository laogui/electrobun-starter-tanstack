# GhostBoard 减法版 PRD（slim/v1）

> 基线：main `b4ec080`（2026-11-04）。本文只定义**这一阶段做什么、不做什么**；交互细节仍以 [PRD.md](./PRD.md) 对应章节为准。两份文档冲突时，范围以本文为准。

## 1. 一句话定位

**GhostBoard 是写东西之前的资料整理台：把网页、截图、文件和笔记摊在一张画布上对照，整理出结论，再导出成 Markdown 带走。**

本地、离线可用、中文友好、免费。

## 2. 先服务谁

**第一类用户：要写东西的学生和中文创作者。** 例如写时评、读书报告、小论文、选题策划、视频脚本前的资料准备。

- 第一号用户是开发者本人：下一次写作任务从头到尾只用 GhostBoard 完成，记录每个卡住的地方。
- 暂不同时服务：时间管理用户、插件开发者、团队协作用户。
- 获客渠道（验证用）：小红书 / B 站的“用画布写时评”演示、少数派、Obsidian 中文社区。
- 对标 Heptabase。差异只有一句：本地、免费、中文友好、专注“写作前”。

## 3. 唯一的核心流程

> 带入素材 → 浏览与编辑 → 分组与连线 → 找回 → 写结论 → 导出 Markdown

所有功能按这条流程判断：**在流程上的保留并打磨；不在流程上的隐藏或冻结。**

## 4. 保留、隐藏、冻结

### 保留（这一阶段的全部产品）

| 类别 | 内容 |
| --- | --- |
| 内容 | Note（BlockNote 长文）、Sticky、Topic（轻量导图）、图片、链接、文件 |
| 整理 | 连线、Group、Folder、标签、多画布、撤销重做 |
| 找回 | `Cmd/Ctrl+K` 搜索、笔记库 |
| 产出 | 聚焦编辑、AI 把选中资料总结进一张 Note、Markdown 导出 |
| 模板 | 空白、Quick Start、读书笔记、头脑风暴导图、Demo |
| 过渡保留 | Checklist（Quick Start 和读书笔记模板在用，下一步并入 Note 的任务列表） |

### 隐藏入口（代码与旧数据都在，开关在 `src/mainview/lib/productScope.ts`）

| 项目 | 原因 | 旧数据 |
| --- | --- | --- |
| 番茄钟、提醒 | 与整理资料无关；提醒只在 App 打开时生效 | 照常显示、搜索、打开 |
| 录音 | 写作场景很少用，多一套麦克风权限与状态 | 照常播放 |
| 设置 → 插件、设置 → 画布类型 | 见下方“冻结” | 已装插件不受影响 |
| 许可证卡片与 100 张免费额度 | 还没有用户，额度只会挡住试用 | 不改动许可证数据 |
| 看板、周计划、冲刺复盘、四象限、咖啡馆模板 | 规划类，不在写作流程上（`HIDDEN_TEMPLATE_IDS`） | 仍可按 id 加载 |

### 冻结（不删代码，停止新开发，不对外宣传）

- 公开插件平台：SDK、签名与更新、URL / ZIP 安装、开发模式、插件文档站与样例。
- 网站的 App、API 与登录（Google OAuth、Resend、Neon 相关）：官网只保留介绍与下载。
- 付费与订阅。

解冻条件：核心流程有一批真实用户在用，并且有人明确提出“需要扩展”或“愿意付费”。

## 5. 下一步（按顺序）

1. **自己用一周**：用 slim/v1 完成一次真实写作，按 PRD §1.3 记录阻断点。
2. **合并找回入口**：笔记库弹窗、游离笔记侧栏、Unlinked Files 合成一个“资料库”，加上搜索共两个入口。
3. **Checklist 并入 Note**：模板改用 Note 内任务列表；旧 Checklist 只读兼容。
4. **标签简化**：主标签 + 次要标签改成一种标签。
5. **评估 Group / Folder 合一**：Folder 作为 Group 的“折叠”状态，用户只需学一个分组概念。先写方案，验证后再动代码。
6. **写一个对外演示**：用一篇时评的完整过程录屏，作为第一条获客内容。

## 6. 这一阶段不做

- 新的卡片类型、新的插件能力、新的动画变体。
- 网页剪藏、PDF 批注、Backlinks、移动端、多人协作。
- 任何以“功能清单更全”为理由的需求。新需求必须来自第 5 节第 1 步记录的真实阻断点。

## 7. 判断做对了

- 开发者本人能只用 GhostBoard 完成一次写作，中途不需要切到别的工具整理资料。
- 5 个目标用户试用后，至少 3 个能不看说明走完核心流程。
- 设置页和创建菜单里，每一项都能说清楚“它在核心流程的哪一步”。
