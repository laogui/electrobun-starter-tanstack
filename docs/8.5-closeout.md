- 标签停留在旧 widget ID，新 extension 按放置 ID 读取，导致标签不可见。现在为每个放置复制一次旧标签，并持久化复制记录；明确清空后不会在后续加载 / 重启时复活，已有放置标签优先。补了两个先失败后通过的数据完整性回归。

- 无法迁移的 legacy widget 因 React Flow 注册表移除旧渲染器而显示空白框。恢复 legacy widget / media / link / recording 的正常与只读渲染入口。实际缺失 widget、缺失及损坏 extension 现在都有明确回退；原文件不被改写，补回测试记录后原引用能重新加载。
- 拒绝可用备份后的错误文案误称“没有可用备份”。已修正中英文，实际原生页面显示原件未覆盖与重试 / 恢复入口。
